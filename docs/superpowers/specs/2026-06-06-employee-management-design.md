## 2. 数据模型设计

### 2.1 标准化字段

对原始 21 个字段重新整理，合并/拆分/统一格式：

```typescript
interface Employee {
  id: string;                // 系统生成唯一ID
  employeeNo: string;        // 工号（如 TA-004）
  name: string;              // 姓名
  gender: "男" | "女";       // 性别
  idCard: string;            // 身份证号
  birthDate: string;         // 出生日期（YYYY-MM-DD）
  age: number;               // 年龄（自动计算）
  phone: string;             // 手机号
  department: string;        // 部门（从职位中提取）
  position: string;          // 职位
  education: string;         // 学历
  address: string;           // 家庭地址
  entryDate: string;         // 入职日期（YYYY-MM-DD）
  status: "active" | "resigned";  // 在职/离职
  resignDate?: string;       // 离职日期（YYYY-MM-DD）
  dormitory: boolean;        // 是否住宿
  signedContract: boolean;   // 是否签署合同
  contractType: string;      // 合同类型（劳动合同/劳务合同）
  contractStartDate: string; // 合同起始时间（YYYY-MM-DD）
  contractEndDate: string;   // 合同期限/结束时间（YYYY-MM-DD）
  contractRemainingDays: number; // 合同剩余天数（自动计算）
  idCardExpiry: string;      // 身份证有效期限
  yearsOfService: string;    // 工龄（自动计算）
  remark: string;            // 备注
  createdAt: string;         // 创建时间
  updatedAt: string;         // 最后修改时间
}
```

### 2.2 自动计算字段

| 字段 | 计算规则 |
|------|---------|
| `age` | 当前年份 - 出生年份 |
| `contractRemainingDays` | `contractEndDate` - 今天 |
| `yearsOfService` | `entryDate` - 今天，格式化为"X年X月" |
| `department` | 导入时从职位字段智能提取（如"装配部主管"→部门="装配部"，职位="主管"） |

## 3. 功能清单

### 3.1 员工列表页

```
┌──────────────────────────────────────────────┐
│  [在职员工 (81)] [离职员工 (5)]                │  ← Tab 切换
│                                              │

│  [+ 新增员工] [📥 导入Excel]                   │  ← 操作按钮
│                                              │
│  ┌─────────────────────────────────────────┐  │
│  │ 姓名 │ 工号 │ 部门 │ 职位 │ 入职 │ 合同到期 │← 表格

│  │ 邹荣兵│TA-004│装配部│主管  │2013..│ 978天   │  │
│  │ ...   │ ...  │ ...  │ ...  │ ...  │ ...     │  │
│  └─────────────────────────────────────────┘  │
│  [编辑] [删除] 每行操作                         │
└──────────────────────────────────────────────┘
```

### 3.2 合同到期提醒

- **红色**：合同已过期（`contractRemainingDays < 0`）
- **黄色**：即将到期（`0 ≤ contractRemainingDays ≤ 60`）
- **绿色**：正常（`contractRemainingDays > 60`）
- Dashboard 顶部横幅提醒"有 X 人合同已过期，Y 人即将到期"

### 3.3 新增/编辑员工

弹窗表单，所有可编辑字段：
- 必填：姓名、性别、部门、职位、入职日期、手机号
- 选填：工号、身份证号、学历、地址、住宿、合同信息等
- 身份证号输入后自动解析出生日期和性别

### 3.4 删除/离职

- 点击删除 → 确认弹窗 → 标记为"离职"并记录离职日期
- 离职员工仍保留在系统中（可在离职 Tab 查看）
- 真正删除需要二次确认

### 3.5 批量导入

- 支持上传 Excel
- 预览导入数据，显示匹配结果
- 自动处理格式不统一的日期
- 导入模式：追加 / 覆盖更新（按工号匹配）
