## 4. P1 — 员工管理

### 4.1 数据来源

你提供的现有员工表格（包含在职 + 离职员工），作为初始化数据和字段参考。

### 4.2 员工分类

### 4.3 功能清单

## 5. P2 — 产品数据中心

### 5.1 数据架构

```
┌──────────────┐     ┌──────────────────┐     ┌─────────────────────┐
│   金蝶系统    │────▶│  同步服务          │────▶│  平台商品基础数据     │
│  商品/库存源  │     │  OAuth + 拉取API  │     │  只读，跟随金蝶更新   │
└──────────────┘     └──────────────────┘     └──────────┬──────────┘
                                                          │ kingdeeMaterialId
                                                          ▼
                                               ┌─────────────────────┐
                                               │  本地商品补充资料     │
                                               │  图纸/3D/生产/包装    │
                                               │  版本管理 + 变更记录   │
                                               └─────────────────────┘
```

- **金蝶**：商品主数据和库存的唯一权威来源。
- **平台**：不允许本地新增商品，只在金蝶商品基础上维护图纸、3D 数据、生产参数、包装规范等补充资料。
- **唯一键**：使用金蝶物料 ID（`kingdeeMaterialId`）绑定商品、库存、附件和补充资料。
- **商品料号**：使用金蝶物料编码，平台字段命名为 `materialNo`。
- **网站产品数据**：仅作为产品分类和参数结构参考，不作为权威数据源。

### 5.2 金蝶同步工具

| 功能 | 说明 |
|------|------|
| OAuth 授权 | 获取金蝶访问权限，复用已跑通的授权能力 |
| 商品同步 | 从金蝶拉取最新商品列表和详情，按 `kingdeeMaterialId` upsert |
| 库存同步 | 从金蝶拉取即时库存，按仓库展示；可用库存、锁库数量、在途数量按金蝶返回字段展示 |
| 停用处理 | 金蝶停用或不存在的商品在平台标记为停用/异常，不删除本地附件和补充资料 |
| 冲突保护 | 金蝶字段覆盖平台金蝶字段，本地补充资料永不被同步覆盖 |
| 同步日志 | 记录同步时间、成功数量、失败数量、错误信息和执行人 |

### 5.3 数据分层

金蝶商品基础数据 + 平台补充资料 = 完整商品档案。

| 数据分组 | 字段示例 | 来源 |
|----------|---------|------|
| 商品基础信息 | 金蝶物料 ID、物料编码/商品料号、名称、规格型号、单位、分类、启用状态 | 金蝶 |
| 仓库库存 | 仓库 ID、仓库名称、即时库存量、可用库存、锁库数量、在途数量、单位、同步时间 | 金蝶 |
| 生产参数 | 扭矩、齿轮参数、材料、温度、工艺要求、设备/工序参数 | 平台补充 |
| 包装规范 | 包装方式、最小包装量、最小出货量、单重(g)、装箱数量、标签/外箱要求 | 平台补充 |
| 图纸和 3D 文件 | 2D 图纸、3D 模型、BOM 表、检验资料、包装文件 | 平台补充 |
| 变更记录 | 版本号、变更原因、上传人、发布时间、当前/历史版本状态 | 平台补充 |

### 5.5 商品列表页

- **不提供新增商品按钮**：商品只能通过“同步金蝶”进入平台。
- **列表主字段**：商品料号、商品名称、规格型号、分类、单位、总即时库存、库存仓库数、金蝶状态、最后同步时间。
- **筛选能力**：关键词搜索、分类筛选、仓库筛选、库存状态筛选、金蝶启用/停用筛选。
- **操作入口**：查看详情、维护资料、下载当前图纸、查看同步记录。
- **库存列**：默认显示总即时库存；点击后进入详情页按仓库展开。

### 5.6 商品详情页（一页全览）

点击商品进入详情页，金蝶字段只读，本地补充资料可维护：

```
┌────────────────────────────────────────────────────┐
│  商品详情：RD-T015 / 金蝶物料ID: 123456             │
├────────────────────────────────────────────────────┤
│ [基础信息] [库存信息] [图纸资料] [3D数据] [生产参数] │
│ [包装规范] [变更记录] [同步记录]                    │
├────────────────────────────────────────────────────┤
│  当前 Tab 内容...                                   │
└────────────────────────────────────────────────────┘
```

- **基础信息**：只读，来自金蝶；展示物料 ID、物料编码、名称、规格、单位、分类、启用状态。
- **库存信息**：只读，按仓库表格展示即时库存量；可用库存、锁库数量、在途数量按接口返回展示，缺失字段显示 `-`，不当作 0。
- **图纸资料**：展示当前有效版本，可展开历史版本下载；上传新版本时填写版本号和变更原因。
- **3D 数据**：维护 3D 模型文件和三维参数，可做版本管理。
- **生产参数**：维护生产参数、工艺要求、设备/工序参数。
- **包装规范**：维护包装方式、最小包装量、最小出货量、装箱/标签要求。
- **变更记录**：展示附件和补充资料的版本变更历史。
- **同步记录**：展示最近同步时间、同步状态、错误信息和同步执行人。

### 5.7 附件和变更管理

- 附件不做简单覆盖，必须以“文档 + 版本”的方式管理。
- 默认展示当前有效版本，历史版本保留可查、可下载。
- 上传新版本必须填写：文档类型、版本号、变更原因、文件。
- 新版本发布后，旧版本自动归档，新版本成为当前版本。
- 支持文件类型：PDF、DWG、DXF、STEP/STP、Excel、图片、ZIP 等。
- 是否需要“审核后生效”待确认；第一版按最终权限规则实现。

### 5.8 功能清单

| 功能 | 说明 |
|------|------|
| 商品列表 | 搜索、分类筛选、仓库筛选、库存状态筛选、表格展示 |
| 同步金蝶 | 一键同步金蝶商品主数据和仓库库存 |
| 商品详情 | Tab 切换，一页展示金蝶基础信息、仓库库存、本地补充资料 |
| 本地资料维护 | 维护生产参数、包装规范、最小包装量、最小出货量、备注 |
| 附件版本管理 | 图纸、3D 模型、生产参数文件、包装规范文件上传和历史版本下载 |
| 同步日志 | 查看每次同步结果、错误原因和更新时间 |
| 数据导出 | 导出商品列表、库存列表、附件清单 Excel/CSV |

### 5.9 不做的

- 不做本地新增商品。
- 不在平台编辑金蝶商品名称、物料编码、单位、规格、库存等金蝶权威字段。
- 不在平台直接删除金蝶商品；只根据金蝶状态标记启用/停用。
- 不把官网产品数据当作主数据来源。

## 7. P3 — AI 智能体（DeepSeek）

### 7.1 技术方案

```
用户提问 → 前端聊天框
         → Express API
         → 搜索相关数据（产品/文档/员工/流程）
         → 拼接上下文
         → DeepSeek API
         → 返回答案
```

用最简单的 RAG 方式：关键词匹配 + DeepSeek 总结，不引入向量数据库。

### 7.2 能力

| 能力 | 示例 |
|------|------|
| 产品查询 | "RD-T015 扭矩多少？""阻尼器有哪些类型？" |
| 文档检索 | "请假流程是什么？""ISO 文件在哪？" |
| 员工查询 | "工程部有谁？" |
| 流程指引 | "客户退货怎么处理？" |

排单建议/生产单生成等后续再考虑。
