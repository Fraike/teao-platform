# 正式工程标准基线实施计划

依据已确认的 `docs/specs/standard-production-baseline-import.md` 实施。只改代码、建立隔离演练库；本计划不授权 Git 提交、推送、真实部署或真实换库。

1. 回归测试：纵向合并值与批注归属、跨行项目号、已确认来源状态与冬季转换。
2. 修复解析与来源政策，保持旧来源规则兼容。
3. 新增只接受两份正式 XLS 的构建入口：读取原件、验证 hash/工作表覆盖、去重卫浴、执行明确转换，生成全新标准库及不可变 manifest。
4. 导入仅生成初始化与来源变更历史；全部原始批注留档，不伪造审批、不生成公告/催审。
5. 新增离线预览、指纹确认、归档换库和开放前回滚工具；测试维护/停写、过期预览、WAL、失败恢复与 revision。
6. 用真实来源演练809条（808生效、1停用）、1264批注关联，逐字段回读核对，验证重复构建和输出。
7. 完成测试、lint、build及发布包检查，交付上线报告与分别确认的下一步。

并行写集：解析/身份、来源政策、离线切换各自独立；主任务负责隔离库构建与集成验证。
