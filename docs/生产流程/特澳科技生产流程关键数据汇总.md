| 要求 | 内容 |
|------|------|
| 录入时效 | 出入库信息录入延迟不超过12小时 |

| 系统校验 | 批次号、规格型号、力值规格等关键字段校验规则 |
| 数据保存 | 所有出入库单据、操作日志、追溯数据修改记录永久保存 |
| 核查频率 | 每月至少1次账、物、卡、系统一致性核对 |

## 流程 8：设备异常处理

**文件：** `7-设备异常处理规范.docx`  
**文件编号：** TA-WI-SC-36（版本 A0）  
**编制：** 肖晓刚

| 项目 | 内容 |
|------|------|
| **目的** | 规范设备异常识别、上报、处置、复盘全流程 |
| **适用范围** | 生产设备、辅助设备、动力设备、检测设备、输送设备及配套附属设施 |
| **涉及部门** | 装配部(1)、注塑部(1)、品质部(1)、行政部(1)、生管部(1)、工程部(1)、总经办(1) |

### 异常三级分类

| 等级 | 定义 | 处置时效 |
|------|------|---------|
| **一级（轻微）** | 设备可正常运行，轻微隐患（异响、参数波动、积尘、螺丝松动） | 15分钟内整改，当日台账登记 |
| **二级（一般故障）** | 部分功能受限、短时停机、单工位影响、无安全风险 | 30分钟内到场，2小时内修复，复杂4小时内出方案 |
| **三级（重大故障）** | 完全停机、安全隐患、可能批量不良/全线停产 | 10分钟内到场，立即启动应急，2小时内初步排查，当日复盘 |

### 标准处置流程（9步）

1. **异常发现** — 开机前/运行中/停机后全程检查
2. **紧急应急**（0-10分钟）— 停机断电/断气/断液，冒烟起火启动消防，设置警示标识
3. **分级上报**（10-20分钟）— 一级报班组长、二级报维修组、三级报车间主管+设备管理部门
4. **现场确认**（30分钟内）— 核实异常现象、评估风险、明确处置方式
5. **故障排查维修** — 逐项排查根因，更换零部件，安全挂牌上锁
6. **试机验证** — 空载+负载试机，确认声音/参数/精度/功能恢复
7. **恢复运行** — 跟踪首件品质
8. **记录归档** — 《设备异常处置记录表》完整记录设备编号/异常现象/原因/处置/耗材/停机时长/人员
9. **复盘改善** — 周度汇总一级二级，三级专项复盘+根因分析
