# 智能卫浴与金蝶商品编码核对（2026-10-16）

## 结论
金蝶实时商品分类“马桶座盖”返回45个商品，Excel智能卫浴为70套盖/座标准，两者粒度不同。按部件逐项比对，有43项唯一候选，其中42项实际扭矩范围文本一致，1项（马志敏／盖CCW29，SP0034-G）两侧实际扭矩均为“/”，不能确认扭矩。
70套中17套盖和座均有唯一候选、9套只有一侧有唯一候选、44套没有唯一候选（含宠物箱的多候选）。45个金蝶商品都有来源候选，43个双向唯一；其余2个编码SP0004-G和SP0031-G都对应原表第29行永联餐具宠物箱盖CW12、10-13。

## 歧义详情核对
两个商品已额外读取详情：均启用，规格10-13、单位个、备注空、自定义字段相同；名称仅空格差异。ID、编码、条码和价格记录存在差异，不足以确认两个商品对应同一项目或不同项目。不能自动选一个，也不能据此擅自停用商品。

## 方法及边界
- 来源：原Excel卫浴工作表70行；金蝶material_group定位分类、material列表完整分页取得45条；核验商品ID和编码唯一。
- 产品型号边界严格匹配，避免PR-T098误匹配PR-T098E。
- CW/CCW方向、标称值和实际扭矩范围文本一致；名称明确盖/座时要求部件类型一致；括号客户型号与已填客户型号不符则排除。
- 数字范围仅统一字符、大小写和空格，未做物理单位换算。双方均无数字范围时只记低信息唯一候选。
- 未使用相似度最高项强行匹配。空白、暂无和共用Q9保留原状，不自动扩展引用。
- 油号、长度、台阶、所有印字及客户归属并非均在金蝶名称/规格中可得，因此“唯一候选”不代表完整工程标准一致，仍需工程确认。
- 逐部件140个位置的分类统计仅为核对位，其中包含空白/暂无及文字说明，不代表140个实际独立商品。

## 建议
保留一套标准的内部ID/编号，在盖和座垫下分别关联金蝶商品ID与编码；先人工确认43个唯一候选。两件产品共用一套审核版本。不用一个SP编码替换整套WY编号；未匹配及歧义项保持空白。
