# 半成品系列与图纸预览实施记录

本地 main 实施，未提交、推送、部署或实际导入。用户已确认三类半成品（塑胶配件、绳子、弹簧.五金）、共用多归属和材料不明确只列候选规则。

## 已实现

- 分类内系列卡片全量自然排序，共用商品在多个系列可见但不复制商品；未知型号归未识别系列，保留原始名称和金蝶规格。
- 名称解析区分型号共用与材料分隔符，保留方向、零件、颜色与材料；成品/半成品缺图过滤显式隔离。
- 所有半成品隐藏客户标准入口和上传范围，忽略旧链接的客户上下文；服务器拒绝带客户范围的上传与发布。
- 批次新增 kind=semi-parts；旧库增量添加 kind，旧批次默认 finished。限定三个分类和子件图路径；成品批量界面不显示半成品批次，半成品扫描暂通过现有管理协作 API 使用。
- 服务器提取 PDF 正文，依据明确共用说明、部件和材料生成待确认候选，并提示材料、颜色和明确模穴差异。无 OCR；正文提取限前30页/10万字符。异常型号和否定适用说明不扩展候选，明确成品/总装或部件未识别的文件另列核对。
- 后端部署依赖加入与前端同版本 PDF.js，避免脱离根目录安装后缺少正文读取依赖；不把 PDF 内容作为指令执行。
