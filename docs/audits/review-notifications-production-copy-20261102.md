# 2026-11-02 审核通知与日报修复本地验收

## 改动范围

- 待审核提交、标准手动/定时催审和停用申请即时通知使用企业微信自建应用，只发指定审核人的账号。不再群内点名，也不保留“查看并审核”长链接。驳回和生产日报保留各自原有群通知。
- 应用 token 缓存并合并并发获取；过期拒绝最多刷新一次；发送超时或不可识别响应标记“不确定”，不自动重试或改发群。发送前复验待审状态、审核人权限与绑定，避免排队后发错人。缺配置/绑定、明确失败和发送不确定均有 UI 提示，不影响已经成功保存的审核业务状态。
- 发布公告保留最小标准号标识、版本和完整适用参数表，取消基本信息、审计记录、原始批注及重复操作指引。所有分类及成对/单件变体的完整字段、冬季要求、单位、多行、扩展字段、0/false 均保留，超长内容按字节安全分段。已入队公告的 payload、状态和发送进度不改写。
- 装配和注塑表单使用 preserve:true 监听未注册的商品 ID/料号。更换商品时通过共享服务按当前金蝶缓存验证部门归属并同步可信字段；只改数量等无关信息时仍允许保留历史商品。

## 启用与边界

管理员需在服务端持久环境配置 `WECOM_CORP_ID`、`WECOM_AGENT_ID`、`WECOM_APP_SECRET`，确认应用可见范围与接口调用权限，并绑定审核人 wecomUserid。未在本轮填写或输出真实密钥，未调用真实企微消息接口。

停用申请只迁移原有即时通知，不新增原先没有的自动/手动催审调度。未自动修复既有业务记录，未改写线上消息队列或配置。所有测试数据独立存放在 /tmp，用户原始 Excel、运行数据、历史资料均保留。本轮未提交、推送、部署或进行真实企微发送联调。
