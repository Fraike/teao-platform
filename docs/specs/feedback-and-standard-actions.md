# 问题反馈与标准操作栏整理

用户确认：所有标准操作按钮保持直接展示，常规操作与审核/催审分组，不收进更多菜单。

## 功能范围
- 侧栏底部固定“问题与建议”，折叠时仅图标并显示悬浮说明。
- 所有已激活用户可提交：数据问题、页面问题、功能建议、其他；描述必填，截图选填，最多3张，每张2MB，限 PNG/JPEG/WebP。
- 自动记录当前页面路径（不含查询参数和片段）、页面名称、提交人、时间；反馈保存在独立 feedback.db，不改变业务数据。
- 员工只可查看自己的反馈，管理员额外有“反馈管理”，支持分页、状态筛选和处理说明；状态为待处理、处理中、已解决。
- 截图仅随有权查看的反馈详情返回，不暴露公开文件链接；服务端校验格式、大小与实际图片头。只按需读取详情，列表不包含图片。
- 修改处理状态按最新管理员身份校验，并校验修订号，避免覆盖已有处理结果。
- 新组件按需加载，使用命名导出、集中类型、CSS modules，不新增第三方依赖。

## 实施与验证
1. 建立隔离的反馈存储与鉴权路由测试，覆盖私有数据、截图校验、分页与并发更新。
2. 新增后台 API、侧栏入口、提交与查询处理界面。
3. 标准表格操作改为常规图标一组，审核/催审另成一组，保持现有权限和冷却。
4. 运行完整测试、Lint、构建以及浏览器交互检查。仅修改代码，不提交、不部署；测试不写真实业务库、不发送群消息。
