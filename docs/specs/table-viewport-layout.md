# 表格视口布局修正

用户授权压缩产品标准页头部，移除顶部横向拖动条，检查并统一其他页面的表格布局。

- 框架固定到动态视口，内容区 flex 子项允许收缩；保留非表格页面的正常滚动。
- 单列表页面由 ResponsiveTable 的 fitViewport 能力实测内容区剩余高度，预留表头、分页和底部横向滚动控件，不再使用各页 100vh 固定减法。
- 默认底部横向控件与表体、表头双向同步；在 macOS 自动隐藏滚动条时仍可见。多表页面使用底部 sticky 控件，不将每一张子表强行撑满视口。
- 产品标准页标题、操作、分类和筛选紧凑排列；文件编码、更新时间及分类说明保留在说明入口中，减少固定占用。
- 商品、客户、供应商、员工、用户管理、报价管理和客户商品等单列表共用 fitViewport；生产日报分组表保留页面滚动。
- 检查宽/窄屏、折叠菜单、分页和多表；保留中文输入隔离与版本审核功能。只改布局，不改数据、不提交、不部署。

## 产品标准页面交互调整（2026-10-14）

- 产品标准页关闭共享表格的额外横向拖动条，保留表格内部原生横向滚动条及视口自适应高度。
- 文件编码、数据更新时间、刷新时间、当前分类生产说明直接显示在标题右侧，窄屏自动换行。
- 新增标准、初始化导入、刷新放到筛选工具栏左侧，保留各自权限控制。
- 点击行或使用 Enter/空格切换单行高亮；行内操作不改变选中状态。
- 新增标准客户名、产品型号前后端均必填，拒绝空白字符串；历史导入不增加必填限制。
- 验证：前端交互回归、后端输入校验、构建和浏览器布局。

## 产品标准与侧栏性能修正（2026-10-14）

- 初始化导入回到标题右上角；新增、刷新继续放筛选工具栏左侧。
- 基线：200 行、Chrome 4 倍 CPU 降速，行点击约 446ms 长任务，侧栏收缩有 477/452/444/179ms 长任务；单元格背景自带 0.2 秒渐变。
- 行选择状态下沉至行组件订阅，只更新旧、新选中行；取消此页面单元格背景渐变，避免视觉延迟。
- 共享表格用最小滚动宽度和 CSS 的 100% 最小宽度适配容器，移除宽度变化驱动 React 状态的监听。
- 产品标准页面隔离侧栏父级状态变更，保留尺寸、滚动、分页和筛选响应。尺寸改为即时切换，避免宽度动画引起大表格连续重排。
- 检查尺寸变化不重渲染单元格、选择互斥与键盘操作、宽窄屏滚动，以及修正后的浏览器性能。

- 产品标准列内容按记录引用缓存，操作列按编辑权限区分 key，权限变化仍立即更新操作按钮。

## 生产日报取消重复横向滚动条（2026-10-14）

- 装配、注塑日报分组表以及汇总页两种明细表关闭 ResponsiveTable 的额外底部横向控件。
- 保留 Ant Design 表格自身的横向滚动及分组表头吸顶，其他页面不调整。
- 验证两个录入页面的分组滚动、表头与表体横向同步、原生滚动条恢复，以及构建和共享表格回归。
