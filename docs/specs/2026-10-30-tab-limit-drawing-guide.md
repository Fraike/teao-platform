# 标签上限与通用图纸指南

用户已确认：包含首页最多10个标签，满额提示先关闭，不自动关闭任何页面或丢弃草稿。所有路由入口统一执行限制，已有标签仍可切换和更新查询条件；旧持久标签恢复时保留首页、活动页并限制数量。

商品详情生产图纸区域增加默认折叠的操作指引，成品与半成品共用。包含检查、错误图先历史版本停用、上传并发布及复查三步；区分成品客户范围与半成品内部资料，说明横向PDF、25MiB、双击150%与拖动等操作。图片改为简洁通用版，保留原图不覆盖；展开后才加载图片，可放大查看，隐藏标签不能覆盖当前页面。
