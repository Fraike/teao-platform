# 商品详情图纸旋转

用户需求：商品详情预览增加旋转按钮，便于现场人员查看。

## 已确认实施范围
1. 在现有PDF预览工具栏增加“向左旋转90°”“向右旋转90°”及“复位”按钮，普通查看人员均可操作。
2. 使用PDF本身旋转角度加用户临时旋转角度进行PDF.js渲染；自动适应宽度/整页及缩放按旋转后宽高重新计算，避免裁切。
3. 临时旋转只影响当前预览，不修改源文件、发布版本、下载文件或打印文件。切换图纸或重新打开时恢复原始方向。
4. 无图纸或尚未加载完成时禁用；复用已加载PDF，不新增金蝶请求或重复下载。
5. 验证旋转四次复原、原生270°样本、缩放/适应视口、切换图纸重置及错误状态。

同步实施的PDF上传需求：当前只做PDF、每页按旋转后的有效显示宽高判断横向；未来3D使用独立标签页。不将“页面横向”误当成文字方向识别。

只改代码与测试，不提交/推送/部署/重启。

验证完成：组件回归覆盖原生270°旋转、左右90°、四次复原、fit尺寸、复位、换src重置、旋转不重复加载。真实浏览器RD-01样本画布由354×250旋转为177×251，复位恢复横向。商品模块回归、lint、前后端类型检查、构建及独立代码复查通过。
