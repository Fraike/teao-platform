# 产品标准提交审核权限

- 已激活普通用户仍可查看已发布标准；新增独立工程部权限 engineering_submit，用户管理显示“产品标准提交审核”。
- 勾选该权限可新增标准、修改草稿、复制标准、选择单人审核并提交；没有该权限时页面不显示编辑入口，直接调用写入API也返回403。
- 管理员仍可直接编辑发布；指定审核人授权仍只针对该标准，不需要提交权限；旧未指定审核流程继续使用 engineering_review。
- 旧 engineering 权限不再作为写入凭据；用户管理将原“工程部”开关替换为清晰的提交开关，不批量修改现有用户授权。管理员根据需要为同事勾选。
- 复用后端实时权限检查与前端能力返回，撤权后立即阻止写入。验证仅查看用户、新提交权限用户、指定审核人与管理员四类流程。
