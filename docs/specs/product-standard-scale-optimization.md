# 产品标准及日报效率优化执行方案（2026-10-14）

用户已授权执行复盘中的当前优化，代码只改不提交、不部署，不对实际业务数据库执行迁移/数据修复脚本。

1. 标准表单按打开会话/编辑对象初始化，分类数据刷新不得覆盖未保存输入。
2. 已确认的原表作废项按完整身份导入为停用；歧义作废项阻止直接发布。记录来源文件哈希、工作表及行号，保留原文与预览备份事务。
3. 标准列表在 SQL 内确定可见版本、过滤、分页；普通用户只读取发布/明确停用版本，工程/审核用户可读工作版本。默认50行、最大200；响应保留 data 数组并增加 total/page/pageSize/updatedAt/version 元数据。列表不加载历史/批注。
4. 前端保留 IME 防抖及高亮，筛选重置页码，取消旧请求；分类缓存按会话隔离；恢复焦点30秒新鲜度判断和版本检查，手动刷新/写后强制加载。
5. 通知独立索引查询，响应 {ok,data,total}，最多20条摘要；隐藏页面停轮询、恢复可见检查，防止乱序/重叠请求。指标加入标准、通知接口，记录耗时和响应体大小。
6. 日报回写权威记录并只重算受影响日期；历史请求隔离、TTL和有界缓存；日期表格缓存排序、使用 rowKey=id，避免全量拷贝。
7. Excel Worker 解析、限制解压后范围、批注按行 Map，稳定预览数据；后端批量复用语句与来源信息，保持10000条上限。
8. 详情历史/批注按需分页；兼容旧接口调用以免脚本和现有审计失效，优化新页面调用路径。
9. 已有规模量测同样数据模型再次量测，与权限/分页/乱序/表单/导入/日报回归一起验证。

未来触发项：日期组服务端明细分页、分组虚拟化、超10000条后台导入任务、跨实例数据库及持久化提醒队列，按真实负载实施，不盲目加基础设施。

执行记录：按模块完成后追加，最终做独立复审。任何方案调整在此注明。

## 完成记录

- 标准服务添加可见版本SQL筛选、分页、复合索引、revision触发器；32页有界缓存按revision与可见范围失效，返回值拷贝防止调用方污染缓存。用户权限加入opaque版本戳，撤权后不会因数据库未变化而继续命中旧视图。
- 页面默认50行，服务端分页；请求取消、分类5分钟会话缓存、恢复焦点30秒新鲜度及轻量版本检测；URL分类只应用一次，模板刷新不会重置当前页。
- 标准详情轻量查询；版本／变更20条分页，原始批注展开后10条分页，按用户可见版本过滤。
- 原表初始化自动拆分客户尾部项目码，项目变体身份稳定；已确认作废完整身份+源hash+工作表清单导入为停用，其他作废（包括基础列）阻止发布；记录sourceRow/hash/sheet。prepared statements复用，批注原文保留。
- 日报整记录权威回写、单日期汇总更新、无关分组引用保留；同记录请求及回写串行，其他记录并行。历史TTL5分钟/100条缓存，乱序隔离、取消及写后/刷新失效。
- Worker解析、批注按行Map、稳定预览行键及及时释放；XLSX在SheetJS解压前检查ZIP中央目录，并流式核实实际解压内容（单条16MB/总64MB/1000条）；实际行/列校验，禁止通过错误dimension静默截断尾行。原10MB/10000记录上限不放开。
- 通知独立待审核SQL，20条摘要及总数；隐藏停止轮询、会话/请求隔离；标准和通知接入耗时/响应字节/行数指标。
- 独立复审4项重要边界均已修复。尾行/解压/作废基础列/保存串行回归验证旧行为RED、新行为GREEN；最终全量测试、构建和定向lint通过。
- 实际Excel全新临时库：760标准，759发布/1停用，10652字段差异0，1194批注精确匹配；重复预览跳过760条。
- 隔离浏览器：服务分页、未保存表单刷新保留、真实XLS与压缩XLSX Worker、按需历史/批注、四种视口原生滚动、两种日报同步与吸顶通过。
