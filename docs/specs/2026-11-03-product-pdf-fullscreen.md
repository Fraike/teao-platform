# 商品图纸浏览器内全屏查看

## 已确认范围

在共享 PDF 查看器增加“全屏查看”按钮，图纸铺满浏览器内容区域。进入后展示图纸名称和“退出全屏”按钮，也可按 Esc 返回。

复用同一 PDF 文档和画布，保留页码、缩放、旋转和拖动能力，避免重新下载、解析。全屏期间锁定背景滚动及交互；退出恢复背景和按钮焦点。切换标签、切换图纸或卸载时自动退出。图纸异常帮助弹窗保持可用。

## 实现任务

1. 共享查看器增加入口和出口。
2. 稳定 portal 容器在原位置与浏览器视口之间移动；样式使用 CSS modules。
3. 回归覆盖状态保留、Esc、退出按钮、标签切换、图纸切换和卸载清理。

仅本地修改；提交、推送、部署分别确认。

## 验证

运行商品专项测试、相关文件 ESLint、生产构建，并在隔离数据的浏览器环境验证全屏尺寸、同一画布、退出清理和无额外 PDF 下载。
