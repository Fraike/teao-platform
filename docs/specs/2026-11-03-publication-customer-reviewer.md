# 发布详情补回客户与审核人（已确认）

同一内部料号可能属于多个客户。发布消息必须使用本次发布版本的客户名称，保留完整名称、标准号与版本号；显示实际审核动作传入的审核人，缺失时取版本审核记录，仍无记录则显示“未记录”。管理员直接发布显示“发布人”，其来源同样优先实际动作及版本发布记录。

共享模板仅生成 markdown_v2 详情，取消独立文本标题及 @所有人。正常只发送一条；超过消息长度限制时按参数行安全分段，每段重复标准、版本、客户和审核人/发布人，保留完整适用参数、多行、单位、0/false 和冬季要求。空参数仍生成可识别详情。纯文本格式化函数同步展示上述身份信息。

API、数据库与 outbox 业务逻辑不变。旧消息快照和发送进度不改写、不重发；待审个人提醒、驳回和生产日报保持现状。

验收：同料号不同客户、完整客户名称与特殊字符、实际审核人优先及历史记录回退、管理员发布人、单条无 @、全部分类/变体参数、长 Unicode 分段、超时续发/去重/中途取消及旧队列快照；运行模板与 outbox 专项、Lint、含服务端类型检查的构建及 diff check。
