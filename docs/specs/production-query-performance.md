# 生产日报查询优化

## 检查结论

装配、注塑列表原先各执行记录计数、日期计数、日期分页、明细查询四条 SQL，相同模糊条件重复执行。前端按十天加载且每日表格无行分页；旧请求没有取消机制。

## 本次调整

- 按日期聚合一次得到记录总数、日期总数和日期分页，随后读取选中日期明细，共两条 SQL。
- 两个页面发起新查询时取消旧请求；卸载时清理请求；过期响应不更新页面或 loading。
- 每日表格每页 50 条，少于 50 条隐藏分页。每日汇总和导出范围保持完整。

## 验证和边界

- 使用独立测试数据库运行现有生产日报测试。
- 内存数据库 100000 条模拟记录，20 次模糊查询平均：原统计/日期查询 16.47ms，新查询 12.92ms；分页与总数一致。非线上端到端基准。
- 仍保留子串搜索语义。`LIKE '%关键词%'` 仍需扫描候选记录；建议继续限制日期范围。超大范围搜索需要进一步评估全文索引的中文与短料号匹配语义。
- 表格行分页只减少 DOM，当前接口仍返回选中日期的全部记录。更大单日数据量需要服务端明细分页与独立汇总接口。
- 未操作线上服务或数据库。
