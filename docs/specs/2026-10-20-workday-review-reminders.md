# 工作日早晨催审

用户已确认：取消两小时循环；北京时间工作日08:00自动提醒一次，与生产日报共用isRestDay及休息日/补班日配置（默认周日休息，周六工作）。启动不立即执行，不在夜间补发；无待审不发送。保留手动催审及五分钟防重复。

调度每日08:00，执行时二次校验时间及工作日。按审核人合并，独立持久化审核人/上海日期的自动发送占位；多实例、重启和发送失败均不在当天重复发送。手动催审不占用当天自动提醒名额，但沿用已有版本级五分钟冷却；自动发送也更新该冷却。审核、驳回、撤回及无效人员仍不提醒。重新提交的即时通知不受影响，定时提醒在下个工作日08:00执行。

排队及限流等待后再次校验实际时间、工作日及Webhook。仅当天08:00—08:59允许自动消息发出（支持长消息分条限流），错过时段取消，禁止队列恢复时夜间补发；手动催审不受该自动时段限制。

测试使用隔离数据库、模拟机器人，覆盖08:00边界、夜间、周六、周日、调休补班、并发、重启、失败不重试、审批完成和手动催审。仅本地实现验证，不提交、不部署线上。

验证完成：完整npm test通过；终审指出的共享队列跨时段发送问题先补失败回归再修复，最终产品标准整套测试通过（末批114/114），构建、语法及diff检查通过，终审复核通过。额外验证超过200条待审完整分条、队列堵塞至22点禁止发送、底层限流后的发送守卫。测试未发送真实消息。本地服务已重启，旧循环退出，新增每日去重表就绪，API健康检查及页面HTTP 200；沿用此前已更新的新机器人地址。不提交、不推送、不部署线上。
