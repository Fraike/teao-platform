# 产品标准导出与打印

用户已明确：checkbox选择具体产品；“导出”是Excel全规格属性，“打印”是生产关键规格/PDF，隐藏审核意见、提交人等流程信息。分类范围和产品选择必须有明显视觉区别。无字段选择器。

## 交互
- 工具栏新增“导出 / 打印”。弹窗将“数据范围”和“产品选择”分为两个独立区域：范围使用下拉选择当前分类筛选结果/全部分类；产品使用分段控件选择全部/勾选指定产品。底部独立“导出Excel”与“打印/PDF”按钮。
- 当前分类默认使用当前列表筛选条件，弹窗明确“当前筛选结果”；全部分类重新按分类读取用户有权查看的最新标准，默认排除停用标准。不可导出不可见数据。
- 指定产品在弹窗内用checkbox选择，支持客户/型号/序号搜索、全选当前搜索结果/取消选择、已选数量；搜索不丢失已选项。切换范围清空选择，防止误导出。
- 确认后生成独立打印预览窗口，按产品分类组织；每个产品用纵向“属性/标准内容”完整表格，避免宽表打印裁列，只包含产品基本信息、版本/状态、分类模板中非空的生产规格（扭矩/测试/齿轮/打码/方向/备注等）。不打印附加导入说明、未知档案字段、审核意见/提交人/审批人/创建更新人及原始批注档案。草稿/待审/停用明显标注，不可当生产标准。
- 窗口内“打印 / 保存PDF”调用浏览器打印，不自动关闭；用户可预览后打印或另存PDF。打印时间、数量、来源系统及执行说明置于文档中。打印隐藏操作按钮；重复表头、长文本自动换行。
- 保留分类说明（汽车客户测试转速、润滑油要求等），与页面共用同一文案。

## 实现与效率
- 使用现有鉴权列表和详情API，不新增导出权限或放宽接口。弹窗懒加载，分页展示选择列表，数据请求支持取消；点击生成后最多4路并发读取详情（summary=true保留所有版本可见性约束与来源批注），不请求整条历史。
- 打印文档由独立HTML生成器输出，严格转义所有用户内容；不使用截图Canvas，以保证中文清晰、可搜索、长内容不截断。使用普通CSS模块与独立打印样式，不新增依赖。
- 切换账号/权限时重置弹窗；生成中取消则终止后续请求、关闭空白窗口；被浏览器拦截弹窗时提示允许弹窗。
- Excel按产品分类分工作表，每条一行，保留所有规格属性（包括附加说明/未知字段）、版本与流程追溯信息；原始批注同时保留单元格批注及独立档案表。所有用户值作为字符串，不转为Excel公式。
- 详情API通过`summary=true&comments=current`仅读取可见版本的当前批注，返回能力标记；旧后端缺少能力时阻止Excel导出不完整文件；打印不请求批注档案，提示更新并重启后端。
