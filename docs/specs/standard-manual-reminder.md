# 手动催促审核

已获用户确认：待审核标准操作区增加“催促审核”，仅提交人和管理员可用，提醒指定审核人。

- 复用定时提醒的发送队列、SQLite 提醒记录，手动发送后下一次定时提醒推迟两小时。
- 同条待审记录最近一次提醒后五分钟内不可手动催促；跨标签页、服务重启和并发请求均由服务端限制。
- 请求携带版本号，发送前重新检查当前状态、提交人、审核人，已审核或版本改变不发送。
- 区分已发送、发送失败、结果不确定、未配置群机器人；未绑定企微账号时仅显示审核人姓名，不假称已 @。
- 按钮使用独立局部状态，避免点击和冷却倒计时导致整张表重新渲染。测试使用隔离数据和模拟发送器，不发真实群消息。

实现顺序：补服务测试 → 共用发送逻辑和路由 → 按钮与状态提示 → 服务端、组件及全量回归、Lint、构建。不提交、不部署、不重启真实提醒任务。
