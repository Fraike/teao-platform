# 国内报价输入兼容调整

## 范围

- 国内报价单价和阶梯单价最多保留 4 位小数，超出部分截断，不四舍五入。
- 输入和预览按实际有效小数位展示，不强制补足 4 位。
- “是否含税”使用“含税 / 不含税”分段选择，底层继续保存 `taxNote` 字符串。
- 历史 `taxNote` 包含“不含税”时选中“不含税”，其他非空历史说明选中“含税”；未操作时保留原文，操作后保存为“含税”或“不含税”。
- 加载报价时保证产品 ID 唯一，使任意产品行均可独立删除。

## 验证

- 纯函数测试覆盖截断、价格展示、含税旧数据识别、重复产品 ID 修复。
- 运行 TypeScript 检查和生产构建。
