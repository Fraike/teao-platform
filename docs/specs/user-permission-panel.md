# 用户权限分组与配置面板

- 用户列表用紧凑摘要和“配置权限”入口替换所有开关堆叠，保持姓名、状态、找回密码与账号操作清晰可见。
- 配置抽屉展示当前账号，分为“页面访问与使用”（业务、生产、人事、工具、基础资料）与“页面内操作”（生产导入、标准提交、标准审核管理）。权限定义集中维护，列表摘要与配置复用。
- 页面权限文案准确说明现有基础操作也随模块权限开放；不把包含读写的现有权限称为“只读”。工程标准默认查看不设虚假开关，说明所有激活账号可查看发布标准。
- 生产导入依赖生产模块权限，无生产权限时不能新增导入授权；已有授权标记未生效，可以关闭撤销。保留原有授权记录，不隐式扩权或清理。
- 标准审核管理明确包含工作版本查看、旧未指定流程审核与停用；新提交记录仍只允许指定审核人审核。
- 单个开关即时保存，保存中锁定该面板开关避免并发；使用后端返回的权限数组更新当前用户，不刷新整个用户列表。失败保持原状态并提示。
- 视觉沿用后台蓝色主色、白色背景、浅灰分区与紧凑字体，列表摘要限制高度，抽屉兼容窄屏，依赖与保存状态直接可见。
- 验收：默认查看与附加操作分类、生产导入依赖、即时保存/失败状态、管理员和待激活账号限制、桌面与窄屏视觉检查。
