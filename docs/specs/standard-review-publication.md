# 标准审核入口、完整群发布与流程说明

- 当前指定审核人在待审记录操作列看到醒目的“审核”按钮，进入完整详情和变更对比后处理；其他用户保留查看详情，不扩大审核权限。
- 审核面板顶部说明任务，底部醒目显示“通过并发布到群”和驳回；通过前确认会向配置的企业微信群发布并@所有人。
- 通过后发布版本号、分类、客户、项目、型号、料号、全部分类参数与额外字段、审核意见、提交/审核信息和当前版本原始批注。保留原始标记及换行，不截断内容。
- 企业微信文本按UTF-8字节拆分成完整有序的多条消息，每包带序号/客户/型号/版本且同群串行，首条@all，后续不重复群提醒；驳回定向@提交人，未绑定企微账号时提示未能@到本人，不发送生产标准公告。
- 审核结果与群发送结果分别返回，群未配置、失败或结果不确定时明确提示；不自动重试可能已送达的消息，不在验收中发送真实群消息。
- 生成可转发的PNG简易流程图及SVG源文件，涵盖提交、指定单人审核、通过群发布、驳回修改与管理员直接发布的现有规则。
