# 产品标准审核修复方案

用户已于 2026-10-13 授权实施此前评审的修复和页面优化。

1. 发布版与修订稿分开读取；只读用户仅能读取已发布版本及其变更，草稿纯内部可见。
2. 编辑、提交、审核绑定 versionId + revision；冲突返回 409，禁止旧页面处理新版本。
3. 操作读取最新账号权限；审计存用户 ID 和姓名快照，提交人独立于创建人；驳回意见后端必填。
4. 审核显示字段差异，历史可查看完整快照，详情显示驳回意见。
5. 导入解析保留多行标记和附加说明；初始化导入由管理员执行，预览 token 绑定内容及库状态，确认全量校验并 SQLite backup。
6. 中文筛选输入隔离渲染、组合期不筛选、结束后防抖；顶部同步横向滚动条，页面回到前台刷新。
7. 使用临时数据库验证状态、权限、冲突、导入；前端构建、回归测试和必要的浏览器检查。

当前功能保持工程部标准录入、审核、发布和查看范围，不接生产日报，不提交或部署，不改真实标准数据。
