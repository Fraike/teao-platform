# 图纸结构分类与浏览器提示

用户已确认修改并提交代码，部署另行确认。

- 仅齿轮阻尼器分类显示图纸结构选择、标签及选择框内结构文字；以金蝶分类 ID 为准，旧档案缺少 ID 时兼容标准分类旧名称。
- 其他分类上传固定传 unspecified，隐藏结构字段，保留主图、补充图及客户范围。现有图纸关联、历史和默认选择规则不迁移。
- PDF 页面解析或渲染失败时在当前标签内提示推荐最新版 Edge / Chrome；网络或权限加载失败保持原错误，不误导用户安装浏览器。
- 无法自动判断所有缺字缺线，提供“显示不完整？”入口。弹窗提供微软官方中文下载页及 Chrome 中文官网，不能保证特定用户网络能访问，不自动下载或跳转。
