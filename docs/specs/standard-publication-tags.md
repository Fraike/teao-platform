# 近期发布与变更标签

- 客户名旁显示互斥的“新标准”或“有变更”Tag；汽车客户现有悬浮提示保持原样。
- 最近14天内通过审核或管理员直发的首次发布为“新标准”；有历史发布版本的修订发布为“有变更”。仅以当前行真实发布时间计算，不以编辑/导入时间计算。
- 旧Excel初始化导入无审核发布时间记录，不作为新发布；原有客户名星号继续提供“有变更”提示。近期首次发布优先显示新标准，不重复两种Tag。
- 草稿、待审核、停用版本不使用近期发布标签；原表星号提示仍按原数据保留。
- 后端列表返回发布时间、审核时间、是否存在更早发布版本；前端按14天窗口计算，不写入业务数据，不改变权限和源表。
