# 生产日报商品分类完整性修复

## 已确认根因
2026-10-15 线上缓存及金蝶实时列表、详情均返回 SP0201-A（RD-T023-60）的 parent_id 为空；并非分页漏取。生产日报当前仅包含成品子分类630条，另有2条直接挂在成品根分类而被排除。

## 实现范围
1. 成品可选项包含成品根分类及全部后代分类；服务端录入校验共用同一规则。
2. API 返回未分类商品的最小身份信息（id、编码、品名），不将其自动归类，也不允许因此绕过部门校验。
3. 更新结果存在未分类商品时显示警告、数量及前5个编码，明确提示在金蝶补分类后重新更新。
4. 不增加金蝶请求，不改金蝶商品，不修写线上缓存或业务数据库。

## 验证
分类根节点/多层后代、无分类、其他分类隔离；API告警传递；前端共享更新提示；工程标准全量回归、构建及lint。

## 上线依赖
SP0201-A 必须在金蝶正确补分类；上线代码不等于完成上游数据修复。提交、部署另行确认。
