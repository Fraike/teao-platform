# 普通用户密码找回

- 登录页提供普通用户找回：仅填写注册时的真实姓名、新密码，不选择管理员。
- 精确匹配已激活普通用户；空白、未匹配或重名不得错误绑定账号，提示联系管理员。管理员恢复入口保留恢复码验证；只有一位激活管理员时省略账号填写。
- 申请保存加盐密码哈希、唯一申请ID、申请时间和原密码版本，不存储或返回明文密码。一次只允许一条待审申请，不允许后提交的密码替换管理员正在审核的申请。
- 用户管理显示申请时间和通过/驳回操作，管理员在处理前确认账号。审批校验当前管理员、申请ID、账号状态和密码版本；通过才更新密码并使旧会话失效，驳回保留原密码。
- 申请7天有效。直接重置密码后清理旧申请，过期申请不能通过；公开提交接口限制密码长度和频率。
- 任务：后端申请与审批、登录表单、用户管理审核、管理员通知、隔离数据测试与浏览器验收。只修改本地代码，不提交或部署生产。
