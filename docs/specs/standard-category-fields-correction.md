# 客户提示与规格属性修正

- 客户名信息图标仅由汽车客户▲触发，悬浮层只显示汽车测试条件；星号继续由现有“有变更”Tag表达，不再生成图标或重复说明。
- 齿形阻尼器 gear_damper 与锁类·同步器 lock_sync 的模板移除 lock_direction，列表、表单、详情、历史参数和审核对比随统一模板更新；其他分类原有属性保持。
- 原始Excel解析、导入身份及数据库历史JSON保留，不做破坏性数据清理；公开业务数据与群公告过滤这两个分类不适用的装锁方向，避免将旧字段当生产属性发布。
- 验证星号不产生图标、汽车提示不重复变更内容、两个分类字段移除及齿条字段保留，导入与群公告回归。
