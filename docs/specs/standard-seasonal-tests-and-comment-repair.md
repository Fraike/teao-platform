展示补充（用户最新确认）：主表、详情和历史参数中的常规值直接按原样显示，不带太阳图标或“夏季”文字；只有冬季值显示雪花图标和“冬季”标签。底层默认值、录入规则及导出语义保持不变。本补充优先于下文原展示示例。

## 用户确定的规则

- 普通录入默认夏季，即常规测试标准；冬季仅少量客户需要，按需填写。
- 同一产品、同一行、同一测试标准单元格展示夏季和冬季，通过图标及文字区别。
- 补全所有单元格批注中没有进入产品变更历史的内容，重点核查SP0006-C测试范围批注，不能漏导、错配或重复导入。

## 本轮只读复核

当前本地SP0006-C对应齿条阻尼器／常州新泉▲／RD-V128-170／2010.0431.0805，源文件第487行。F487测试范围批注完整归档，10条测试范围变更实际已经存在，包括2025-02-18夏季120-160与2025-11-01冬季100-140；这10条旧记录source_cell为空。主表仍只显示test_standard=120-160，详情抽屉只请求summary、不显示原Excel变更。不能据此把所有10条再追加一次，也不能据本地情况断言用户正在访问的另一个环境已有这些记录。

常规表760个产品均唯一对应，1194个非空产品批注精确归档。旧结构化变更核验仍有20个正文批注的25行未完整对应。其中SP0006-C的B487客户批注把料号2010.0431.0805误解析为日期2010-04，正文被截断。正文归档未丢失；待修的是结构化变更和可见性。

SP0008-E的F641明确存在2026-02-04“取消冬季扭矩”，不导入猜测的冬季值。主表K1表头批注属于表级说明，不凭空挂到某个产品；空批注、仅作者、仅日期与正文批注分别记录。

## 展示和数据方案

1. 沿用fields.test_standard保存夏季常规值，新增可选fields.winter_test_standard，避免批量重写所有旧产品。仅在已有test_standard的分类增设配套字段；智能卫浴盖/座等其他专用测试属性不擅自改变含义。
2. 测试标准列内部两行：太阳图标＋“夏季 120–160”，雪花图标＋“冬季 100–140”。图标用现有Ant图标体系，保留文字和可访问名称，不单靠颜色辨识。无冬季要求只展示夏季行，空值保留缺失状态，不凭空补数值。表头不高亮、不拆成两列、不额外扩大表格总宽。
3. 新增/编辑表单将原测试标准标为“夏季／常规测试标准”，原输入值原样保留，新增“冬季测试标准（选填）”；无需让用户先选择季节。复制、分类切换、删除冬季值、修订和审核差异必须正确处理。普通用户仍走审核，管理员行为沿用现有权限。
4. 详情和历史版本使用同一格式；已存版本若没有冬季字段，不能借当前版本的冬季值补写历史快照。主表搜索/筛选纳入冬季值。
5. SP0006-C初始化夏季120-160、冬季100-140，依据F487批注明确值，保留原始批注及来源位置。只补冬季测试字段，不擅改torque_standard或单位，不自动按日期/温度切换当前执行范围。
6. Excel导出独立列出夏季／常规、冬季测试范围且保留批注；打印和企微完整属性表同步列出两套值，缺少冬季时不产生空冬季占位。新版Excel导入能够识别明确冬季列；批注识别出的季节候选先预览，涉及取消/冲突/缺少数值不得自动应用。
7. 从列表提供明确的“测试标准变更”入口或详情中的按需加载区，展示该产品测试范围完整变更和F487原文，避免仅有当前参数时误以为变更丢失；保留分页和按需请求，主列表不逐产品加载全部批注。

## 批注补全和纠错流程

1. 编写独立只读预览工具，扫描当前可用来源文件全部sheet和所有单元格；按来源hash、sheet、行、列、完整产品身份与版本关联，不能仅按序号或客户名匹配。新卫浴公共批注按已确认盖/座关联处理。
2. 对原始批注、结构化变更、字段归属、日期、source_cell分别核对。正文按明确日期块保留换行；日期仅在合理位置且年月日合法时识别，料号/型号中的数字不当日期，无日期明确保留无日期。批注中嵌入多个日期或歧义内容保留全文及待核查提示，不丢弃尾部正文、不猜日期。
3. 输出逐产品差异清单：原文已存在、历史缺失、错误日期/截断、仅缺来源关联、无法唯一匹配。已有语义等价记录只补来源，不再插入；SP0006-C的10条测试范围变更须逐条列入预览。
4. 旧解析记录的纠错只针对来源与身份可证明的机器导入记录；逐条展示旧值、新值和原因。无法证明来源的记录不覆盖；人工变更、审批、版本、发布状态均保留。单纯补历史不触发重新发布、定时催审或群广播。
5. 默认preview，不在预览时调用会迁移/写库的初始化代码。apply前制作SQLite一致性备份，将原始受影响记录及预览归档，校验目标库指纹/版本未变化，在事务内执行，遇歧义停止。第二次相同执行必须为零新增、零重复；query revision更新以使前端刷新。
6. 此次确认仅覆盖本地数据修复；若实际页面连接其他环境，先明确目标与只读复核后另行确认，不远程执行或部署。不得清库、套用全量基线替换、覆盖data目录。

2. 冬夏字段与展示：共用组件、录入、审核差异、详情/历史、筛选及Excel/PDF/企微输出。

4. 确认预览与备份后应用本地数据修复、回归验收，不提交、不推送、不部署。
