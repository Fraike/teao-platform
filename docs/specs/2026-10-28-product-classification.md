# 商品分类与成品图纸入口调整

用户已确认本方案并授权实施，沿用 codex/product-drawing-management 分支；不提交、推送或部署。

- 分类依据金蝶分类ID和父子关系，而非显示名称。商品列表为可点击分类树，默认成品/齿轮阻尼器，支持父节点查看整组、分类数量、搜索状态联动与返回状态保留。
- 成品、半成品分开；半成品保留查询，不计入成品缺图待办。商品详情仍默认生产图纸。
- 标准名称：齿轮阻尼器、圆筒阻尼器、齿条阻尼器、其他锁扣.铰链 / 同步器（保留合并）、空气拉绳阻尼器、空气拉杆阻尼器、马桶座盖。保留内部key和参数模板，直接更新基础名称，不产生标准版本。
- 未关联金蝶按标准key映射；锁扣/同步器未确定细类时进入成品待分类。金蝶存在但未分类的商品不按名称或料号前缀猜分类。
- 商品接口返回categoryId/group/categories；分类和状态筛选在已读取的数据上完成，不逐次访问金蝶。URL记录分类、关键词、状态和页码；详情返回链接仅允许回到本地商品列表。
- 标准导入兼容旧名称及新名称，卫浴工作表同时识别智能卫浴/马桶座盖；源文件中的原始名称和历史来源校验依据保持可识别。
