# 修复资料表格高度反馈收缩

属于前次共享表格布局优化的回归修复，不变更业务数据或页面功能。

原因：自动高度的内容容器被当作可用区域底边。表格高度改变又改变其父容器高度，ResizeObserver 再次扣除表头、分页、滚动条等空间，形成反馈循环，最终收缩到最低 80px。

修复：默认以最近页面滚动视口作为稳定底边，不再根据显示方式或与视口的父子关系猜测高度约束。确实由固定页面高度约束的 flex 区域使用显式边界标记，保留产品标准等已知布局的内边距。反复测量应收敛，窗口变化和表头变化仍正常适配。

验证：新增自动高度父容器反馈回归；检查客户、供应商、客户商品三个真实页面多次测量后的高度稳定与窗口缩放适配；回归产品标准虚拟滚动、隐藏标签、底部横向滚动条。完成测试、lint、类型检查与构建。只改代码，不提交、推送、部署或重启服务。
